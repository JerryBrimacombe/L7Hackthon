# Project guide

This folder contains the generated benchmark website and the supporting documentation for people who are new to the project.

## Start here

- [Getting started](GETTING_STARTED.md): install the project, find the data, run the tests, and create your first leaderboard.
- [Concepts and results](CONCEPTS.md): understand the two cohorts, the train/test dates, ranking metrics, calibration, and the ceiling model.
- [Troubleshooting](TROUBLESHOOTING.md): solutions to common setup, data, model, and chart problems.
- [Contributing](../CONTRIBUTING.md): add a model, update documentation, or run the same checks used by CI.
- [Generated benchmark](index.html): the latest HTML leaderboard and charts, when it has been generated.

## What is generated?

`index.html` and the images under `charts/` are generated by:

```powershell
python -m covidbench.compare --html
```

Do not edit the generated page by hand. Change the source text in `covidbench/compare.py`, rerun the command, and check the resulting page.

The benchmark writes JSON result files to `results/`. Those files are intentionally ignored by Git because each run has a timestamp. They can be regenerated with `covidbench.run`.
